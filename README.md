사이트에 공개 확정하지 않고 플레이스홀더로 둔 항목입니다.

## 상담 문의 폼 (Web3Forms)

`contact.html` 문의 폼은 mailto 대신 **Web3Forms** `fetch` POST로 제출합니다.  
수신: `kaaram21@kapaland.co.kr`

1. [web3forms.com](https://web3forms.com)에서 `kaaram21@kapaland.co.kr`로 Access Key 발급(이메일 인증)
2. `assets/js/form-config.js`의 `accessKey`에 UUID 붙여넣기(또는 시크릿 `WEB3FORMS_ACCESS_KEY`로 부모 에이전트에 전달)
3. 자세한 절차: `ops/WEB3FORMS.md`

키가 없으면 제출 시 한국어 안내 + 전화/카카오톡 유도만 표시됩니다.
